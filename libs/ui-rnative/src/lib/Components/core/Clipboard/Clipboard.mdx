## Introduction

**Clipboard** copies a value the user needs, such as an address, an ID or a code. It owns the copy behavior and the copied state; the element it renders only triggers it. Pressing copies the value and switches the copy icon to a check icon for 3 seconds by default.

Clipboard renders nothing by itself: its `render` prop returns the element that triggers the copy. Render a **ClipboardInput**, a full-width surface displaying the value, or any other component, such as a `Button` or an `IconButton`.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=23359-110294).

## Anatomy

- **Clipboard**: the behavior. It copies `value`, tracks the copied state and passes it to `render`.
- **ClipboardInput**: the input-style visual. It displays a `label` (long values wrap onto multiple lines) and an `icon`; pressing anywhere on it highlights the icon.

### Custom render

`render` receives the copy state and returns the element that triggers the copy:

- `handleCopy`: copies the value. Resolves `false` when the copy fails or Clipboard is disabled, e.g. to show an error.
- `Icon`: the copy icon, or the check icon while the copied state lasts.
- `statusLabel`: the translated "Copy" label, or "Copied" while the copied state lasts.
- `isCopied` and `value`, for anything else.

<Canvas of={ClipboardStories.WithCustomRender} />

## Accessibility

- ClipboardInput is exposed as a button. Use `statusLabel` in the trigger's accessibility label: the value followed by "Copy" for a ClipboardInput, or "Copy" alone for an `IconButton`'s `accessibilityLabel`. It switches to "Copied" once the value is copied (translated with the library locale).
- Clipboard also announces "Copied" to VoiceOver and TalkBack, since they don't re-read the label of the focused trigger when it changes.
- The copied state only shows when the clipboard write succeeds.

## Setup

Install and set up the library with our [Setup Guide →](?path=/docs/getting-started-setup--docs).

Clipboard writes through [`expo-clipboard`](https://docs.expo.dev/versions/latest/sdk/clipboard/), a peer dependency of the library. Install it in your app:

```sh
npx expo install expo-clipboard
```
