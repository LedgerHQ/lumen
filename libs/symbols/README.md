# @ledgerhq/lumen-symbols

Symbol assets for the Lumen design system, shared by web and React Native.
One package, one version, each asset family in its own subfolder.

| Subfolder | Contents          | Import                                         |
| --------- | ----------------- | ---------------------------------------------- |
| `lottie/` | Lottie animations | `@ledgerhq/lumen-symbols/lottie/<name>.json`   |

## Install

```bash
npm install @ledgerhq/lumen-symbols
```
