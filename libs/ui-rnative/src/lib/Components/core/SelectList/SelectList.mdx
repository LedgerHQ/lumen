## Introduction

SelectList is a data-driven, composable selection list designed to be embedded inside a `BottomSheet`, a new screen, or any container.

It handles **selection state**, **automatic grouping** (via a `group` field on items), and exposes a `renderItem` callback for full control over item rendering.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=15941-6709&m=dev).

## Anatomy

<Canvas of={SelectListStories.Base} />

- **SelectList**: Root component managing selection state and item processing
- **SelectListTrigger**: Input-style trigger with floating label and chevron — displays the selected value and opens a BottomSheet on press
- **SelectListContent**: Iterates items, renders group labels and separators automatically, calls `renderItem`
- **SelectListItem**: Pressable item with selection check mark
- **SelectListItemLeading**: Slot for leading visuals (icons, avatars)
- **SelectListItemContent**: Flex column for title + description
- **SelectListItemContentRow**: Horizontal row for placing elements side-by-side (e.g. title + tag)
- **SelectListItemText**: Styled title text
- **SelectListItemDescription**: Styled description text
- **SelectListSearch**: Search input that filters items by label (default) or via a custom `filter` function

## Basic usage

> **Recommended:** prefer the [type-safe variant](#type-safe-variant) below. It ties `value`, `items[].value`, `SelectListItem.value`, and the `renderItem(item).meta` shape to one literal union plus an optional `TMeta`, dropping the `as Meta` casts in `renderItem`.

```tsx
import {
  SelectList,
  SelectListContent,
  SelectListItem,
  SelectListItemContent,
  SelectListItemText,
} from '@ledgerhq/lumen-ui-rnative';

const items = [
  { value: 'a', label: 'Option A' },
  { value: 'b', label: 'Option B' },
];

function MyList() {
  const [value, setValue] = useState<string | null>(null);

  return (
    <SelectList items={items} value={value} onValueChange={setValue}>
      <SelectListContent
        renderItem={(item) => (
          <SelectListItem value={item.value}>
            <SelectListItemContent>
              <SelectListItemText>{item.label}</SelectListItemText>
            </SelectListItemContent>
          </SelectListItem>
        )}
      />
    </SelectList>
  );
}
```

## Type-safe variant

`SelectList` and its subcomponents communicate via context, so TypeScript cannot connect `value` / `items[].value` / `SelectListItem.value` on its own. A typo compiles. `createSelectList<T, TMeta>()` ties them together via one literal union (`T`) and an optional meta shape (`TMeta`) that flows into `renderItem(item)`, removing the `as` cast on `item.meta`.

```tsx
import { createSelectList } from '@ledgerhq/lumen-ui-rnative';
import type { SelectListItemData } from '@ledgerhq/lumen-ui-rnative';

type Network = 'eth' | 'sol' | 'btc';
type NetworkMeta = { ticker: string; ledgerId: string };

const NetworkList = createSelectList<Network, NetworkMeta>();

const NETWORKS: SelectListItemData<Network, NetworkMeta>[] = [
  { value: 'eth', label: 'Ethereum', meta: { ticker: 'ETH', ledgerId: 'ethereum' } },
  { value: 'sol', label: 'Solana', meta: { ticker: 'SOL', ledgerId: 'solana' } },
  { value: 'btc', label: 'Bitcoin', meta: { ticker: 'BTC', ledgerId: 'bitcoin' } },
];

function Example() {
  const [value, setValue] = React.useState<Network | null>('eth');

  return (
    <NetworkList.SelectList items={NETWORKS} value={value} onValueChange={setValue}>
      <NetworkList.SelectListContent
        renderItem={({ value, label, meta }) =>
          meta ? (
            <NetworkList.SelectListItem value={value}>
              <NetworkList.SelectListItemContent>
                <NetworkList.SelectListItemText>{label}</NetworkList.SelectListItemText>
                <NetworkList.SelectListItemDescription>
                  {meta.ticker}
                </NetworkList.SelectListItemDescription>
              </NetworkList.SelectListItemContent>
            </NetworkList.SelectListItem>
          ) : null
        }
      />
    </NetworkList.SelectList>
  );
}
```

## Inside a BottomSheet

Use `SelectListTrigger` as the input-style trigger — it provides a floating label that animates up when a value is selected, and a chevron indicator. Pass children only when a value is selected so the label stays centered when empty.

```tsx
import {
  SelectList, SelectListContent, SelectListItem,
  SelectListItemContent, SelectListItemText, SelectListTrigger,
  BottomSheet, BottomSheetHeader, BottomSheetView,
  useBottomSheetRef, Text,
} from '@ledgerhq/lumen-ui-rnative';

function CurrencyPicker() {
  const [value, setValue] = useState<string | null>(null);
  const ref = useBottomSheetRef();
  const selected = items.find((i) => i.value === value);

  return (
    <>
      <SelectListTrigger
        label='Currency'
        onPress={() => ref.current?.present()}
      >
        {selected && <Text lx={{ color: 'base' }}>{selected.label}</Text>}
      </SelectListTrigger>
      <BottomSheet
        ref={ref}
        enableDynamicSizing
        snapPoints={null}
        onClose={() => ref.current?.dismiss()}
      >
        <BottomSheetView>
          <BottomSheetHeader title='Pick a currency' />
          <SelectList
            items={items}
            value={value}
            onValueChange={(v) => { setValue(v); ref.current?.dismiss(); }}
          >
            <SelectListContent
              renderItem={(item) => (
                <SelectListItem value={item.value}>
                  <SelectListItemContent>
                    <SelectListItemText>{item.label}</SelectListItemText>
                  </SelectListItemContent>
                </SelectListItem>
              )}
            />
          </SelectList>
        </BottomSheetView>
      </BottomSheet>
    </>
  );
}
```

## Grouping

Add a `group` field to items — labels and separators are rendered automatically:

```tsx
const items = [
  { value: 'btc', label: 'Bitcoin', group: 'Crypto' },
  { value: 'eth', label: 'Ethereum', group: 'Crypto' },
  { value: 'usd', label: 'US Dollar', group: 'Fiat' },
];
```

## Controlled vs uncontrolled

Use `value` + `onValueChange` (controlled) when SelectList is inside a BottomSheet — the sheet unmounts children on dismiss, so internal state is lost. Use `defaultValue` (uncontrolled) only when the component stays mounted (e.g. inline in a screen).

## Custom item layout with meta

Use `meta` for arbitrary data, and sub-components for layout:

```tsx
const items = [
  { value: 'eth', label: 'Ethereum', meta: { ticker: 'ETH', tag: 'ERC-20' } },
];

<SelectListContent
  renderItem={(item) => {
    const meta = item.meta as { ticker: string; tag: string };
    return (
      <SelectListItem value={item.value}>
        <SelectListItemLeading>
          <Spot appearance='icon' icon={Wallet} />
        </SelectListItemLeading>
        <SelectListItemContent>
          <SelectListItemContentRow>
            <SelectListItemText>{item.label}</SelectListItemText>
            <Tag label={meta.tag} appearance='gray' size='sm' />
          </SelectListItemContentRow>
          <SelectListItemDescription>{meta.ticker}</SelectListItemDescription>
        </SelectListItemContent>
      </SelectListItem>
    );
  }}
/>
```
