## Introduction

Toasts are brief, non-blocking messages that confirm an action or surface a
status. They appear in a queued stack, are timed by status, and can carry a
single action.

Mount `Toaster` once and call `toast` from anywhere — no provider or hook
required. `Toaster` owns the queue, timing, and placement, and renders each
item for you. `position`, `maxItems`, `insets`, and `durations` configure that
queue.

### Appearance

Appearance drives the leading icon and the default timing:

- **info** (default): general confirmation. Auto-dismisses after 5s.
- **success**: positive outcome. Auto-dismisses after 5s.
- **warning**: caution. Persists until dismissed.
- **error**: failure. Persists until dismissed.
- **loading**: `toast.loading` shows a spinner. Persists until updated or dismissed.

### Actions

Pass `action` with a label and `onAction`. Pressing it never dismisses the
toast, so it is well suited to a retry.

The action's placement is automatic. While the title and the action fit on
one row, the action sits inline beside the title. Otherwise the action drops
to its own row underneath, aligned with the title. The title itself wraps,
then truncates with an ellipsis past five lines.

### Dismissal

Unlike web, there is no close icon: toasts are dismissed by swiping left or
right, unless `dismissible` is `false`.

Each status has a Lumen default: info and success auto-dismiss after 5s;
warning and error persist. Override globally with `Toaster`'s `durations`,
or per item with `duration` — milliseconds, and `0` disables auto-dismiss.
Duration is resolved when the item is created, and again when an update
changes appearance, loading, or duration. Timers start only when an item
becomes visible, and touching a toast — holding it or dragging it mid-swipe —
pauses its timer; releasing resumes from the remaining time. An update that
changes appearance, loading, or duration restarts the timer at its newly
resolved duration (for example loading to success).

### Programmatic dismissal

`toast.notify` and the appearance shortcuts return `{ id }`. Pass that id to
`toast.dismiss` when the toast is no longer relevant. `toast.dismissAll`
clears the queue.

### Position

`position` anchors the queue to the `top` or `bottom` of the screen — there
are no left, right, or center variants on React Native. Items enter from that
same edge, and clear the safe area automatically. Use `insets` to clear extra
obstructions such as a custom tab bar.

### Queue

Up to `maxItems` toasts are visible at once (default 1, vs. 3 on web). Extra
items wait in a FIFO backlog and appear as slots free up. Items waiting in the
backlog are stacked on the pile, so they slide out from behind the visible
toasts instead of entering from the edge.

### Accessibility

- Each toast is announced when it appears or its title changes. Android
  TalkBack reads the surface's `accessibilityLiveRegion` (`assertive` for
  warning and error, `polite` otherwise); iOS VoiceOver has no live regions,
  so `Toaster` posts the title as an announcement, interrupting current
  speech only for warning and error.
- Screen readers capture swipes, so `Toaster` exposes each toast as a single
  element labelled by its title, with dismissal and the inline action as
  accessibility actions (VoiceOver rotor, TalkBack actions menu). On iOS the
  two-finger escape scrub also dismisses. Setting `dismissible` to `false`
  removes both the swipe and the dismiss action.
- Touching a toast pauses its auto-dismiss timer (the native equivalent of
  web hover), satisfying "pause on timed content".

are plugging the item into a notification system you already own. You then
handle queueing, timing, and dismissal yourself.

### Setup

Mount `Toaster` once, near the app root — it takes no children and renders
the queue viewport as an absolutely-positioned overlay, so there is no
separate viewport to mount. Mounting more than one duplicates every toast on
screen and logs a console warning. Requires
`react-native-gesture-handler`'s `GestureHandlerRootView` and
`react-native-safe-area-context`'s `SafeAreaProvider` above it in the tree:

```tsx
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { Toaster } from '@ledgerhq/lumen-ui-rnative';

function App() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <Toaster position='bottom' maxItems={1} />
        <Screens />
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```
