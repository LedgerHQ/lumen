# MediaImageGroup

<CustomTabs>
  <Tab label="Overview">

## Introduction

MediaImageGroup displays a stack of overlapping media images. When there are more items than `maxVisible`, the last slot becomes a `+N` badge with the number of hidden items.

## Anatomy

<Canvas of={MediaImageGroupStories.Base} />

- **Slot**: Ring around each item, sized by the group
- **Item**: A `MediaImage`, or the element returned by `renderItem`
- **Overflow badge**: `+N` slot shown when the data exceeds `maxVisible`

### Overflow

`maxVisible` counts the overflow badge. With `maxVisible={4}` and 6 items, 3 items and a `+3` badge are displayed. The badge reads `99+` beyond 99 hidden items.

<Canvas of={MediaImageGroupStories.WithOverflow} />

### Disabled

Set `disabled` to dim the items and the `+N` badge. Custom items rendered with `renderItem` inherit it.

<Canvas of={MediaImageGroupStories.Disabled} />

To dim a single item, set `disabled` on that item in `data`. The `+N` badge and the other items stay enabled.

<Canvas of={MediaImageGroupStories.DisabledItem} />

### Fallback and loading

Each item accepts the `MediaImage` fallback and loading props.

<Canvas of={MediaImageGroupStories.WithFallback} />

### With Tooltip

The root forwards its ref and props, so the group can be wrapped as a tooltip trigger. Add `tabIndex={0}` to make it reachable by keyboard.

<Canvas of={MediaImageGroupStories.WithTooltip} />

## Accessibility

- The root uses `role="group"`. Provide an `aria-label` describing the group, and `overflowLabel` to name the `+N` badge.
- Each item keeps the accessibility of the element it renders, so give every item a meaningful `alt`.
