## Introduction

Snackbars are brief, non-blocking messages that confirm an action or surface a
status. They appear in a queued stack, are timed by status, and can carry a
single action. Mount a `SnackbarProvider` once and trigger snackbars imperatively
with the `useSnackbar` hook.

## Anatomy

<Canvas of={SnackbarStories.WithAction} />

- **Leading (optional)**: a status icon for success, warning and error, or a
  spinner while loading. Info has no icon.
- **Title**: the message, shown on a single line and truncated.
- **Action (optional)**: a single text button. Pressing it never dismisses the
  snackbar.
- **Close**: dismisses the snackbar. Hidden when `dismissible` is `false`.

### Appearance

Appearance drives the leading icon and the default timing:

- **info** (default): general confirmation. Auto-dismisses after 5s.
- **success**: positive outcome. Auto-dismisses after 5s.
- **warning**: caution. Persists until dismissed.
- **error**: failure. Persists until dismissed.
- **loading**: a spinner via the `loading` flag. Persists until updated or dismissed.

<Canvas of={SnackbarStories.AppearanceShowcase} />

### Position

Position the snackbar at the top, bottom, left, right, or center of the screen.

<Canvas of={SnackbarStories.With} />

### Timing

Each status has a Lumen default (`short` = 5s, `medium` = 8s, `infinite`).
Override globally with the provider's `durations`, or per item with `duration`
(a preset or a number of milliseconds). Duration is resolved when the item is
created, and again when an update changes appearance, loading, or duration.
Timers start only when an item becomes visible, and hovering the stack pauses
them — leaving the stack restarts the full duration. An update that changes
appearance, loading, or duration also restarts the timer (for example loading
to success).

### Queue

Up to `maxItems` snackbars are visible at once (default 3). Extra items wait in a
FIFO backlog and appear as slots free up. The newest visible item sits closest to
the anchored edge. Corner stacks slide in from the side; center stacks slide in
from the top or bottom.

### Accessibility

- Info, success and loading announce politely (`role="status"`); warning and
  error announce assertively (`role="alert"`).
- Focus is never moved into the snackbar.
- Hovering the stack pauses the timers, satisfying "pause on timed content".
  Leaving the stack restarts the full duration.

### Loading and updates

Start a loading snackbar, then update it in place to success or error:

```tsx
const { id } = snackbar.loading({ title: 'Uploading…' });

snackbar.update(id, {
  appearance: 'success',
  loading: false,
  title: 'Upload complete',
});
```

### Binding a promise

```tsx
snackbar.promise(saveProfile(), {
  loading: { title: 'Saving…' },
  success: { title: 'Profile saved' },
  error: { title: 'Could not save', action: { label: 'Retry', onAction: retry } },
});
```
