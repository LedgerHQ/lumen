# Tooltip

## Introduction

Tooltips provide contextual information on hover or focus, helping users understand interface elements without cluttering the main UI.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=6387-409).

## Features

- **Default delay**: 200ms before showing, to prevent accidental triggers
- **Trigger-origin animations**: Slides out of its trigger on enter and back into it on exit
- **Collision handling**: Flips to the opposite side when there is not enough room in the viewport

## Properties

### Placement & Animations

The tooltip always slides out of its trigger, following the side it is actually rendered on (including after collision flipping):

- top (default): Slides up from the trigger
- bottom: Slides down from the trigger
- left: Slides left from the trigger
- right: Slides right from the trigger

## Accessibility

- Opens on pointer hover and on keyboard focus of the trigger
- Closes on `Escape`, when the pointer leaves, or when the trigger loses focus
- Content has `role="tooltip"` and is linked to the trigger via `aria-describedby`
- Tooltips are not focusable: keep content to plain text, with no links or buttons
