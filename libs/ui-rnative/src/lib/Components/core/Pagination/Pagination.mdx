## Introduction

Pagination provides page navigation for lists and other paginated content. It renders previous and next controls, numbered page buttons, and ellipsis markers when the page count is large.

Use it as a **standalone** component: wire `page`, `totalPages`, and `onPageChange` from your data layer.

## Anatomy

The Pagination consists of:

- **Previous control**: `IconButton` with a chevron left icon; disabled on the first page
- **Page buttons**: circular buttons for each visible page, in a horizontal scroll area; the active page uses a filled background
- **Ellipsis**: non-interactive marker when pages are collapsed
- **Next control**: `IconButton` with a chevron right icon; disabled on the last page

In `compact` density, the page buttons and ellipsis are replaced by a "current of total" label.

### Few pages

When all pages fit in the visible range, every page is shown without ellipsis.

<Canvas of={PaginationStories.FewPages} />

### First and last page

On the first page, the previous control is disabled. On the last page, the next control is disabled.

### Density

Use `density='compact'` where space is tight. It keeps the previous and next controls and shows the current position as a localized "current of total" label instead of page buttons.

In `expanded` density, the page buttons scroll horizontally between fixed previous and next controls when they don't fit, and the active page is kept in view. Prefer `compact` when you don't need direct access to each page.

## Accessibility

- The root view exposes an accessible name
- Previous and next controls expose dedicated `accessibilityLabel`s
- Each page button has an `accessibilityLabel` and the active page sets `accessibilityState.selected`
- Ellipsis markers are hidden from assistive technology
- In `compact` density, the "current of total" label is a polite live region on Android, so page changes are announced

## Basic usage

```tsx
import { Pagination } from '@ledgerhq/lumen-ui-rnative';
import { useState } from 'react';

function MyComponent() {
  const [page, setPage] = useState(1);
  const totalPages = 10;

  return (
    <Pagination page={page} totalPages={totalPages} onPageChange={setPage} />
  );
}
```

## Compact

```tsx
import { Pagination } from '@ledgerhq/lumen-ui-rnative';
import { useState } from 'react';

function MyComponent() {
  const [page, setPage] = useState(1);

  return (
    <Pagination
      page={page}
      totalPages={8}
      density='compact'
      onPageChange={setPage}
    />
  );
}
```
