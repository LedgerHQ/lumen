New sticky footer component pinned below the scrollable region. Accepts `style` and `lx` props. Pass a bottom margin/padding to clear the Android 3-button navigation bar if needed.

### BottomSheetContent

New non-scrollable content wrapper with standard horizontal and vertical paddings built in. Use it to easily apply bottom sheet spacings
