## Introduction

**Clipboard** displays a value the user can copy, such as an address, an ID or a code. The whole surface is pressable: pressing it copies the value and switches the copy icon to a check icon for 3 seconds.

## Anatomy

- **Value**: the text that is displayed and copied. Long values wrap onto multiple lines.
- **Icon**: the copy icon, replaced by a check icon once the value is copied. Pressing anywhere on the clipboard highlights it.

## Accessibility

- Exposed as a button. Its accessibility label is the value followed by "Copy", then "Copied" once the value is copied (translated with the library locale).
- The copied state only shows when the clipboard write succeeds.

## Setup

Install and set up the library with our [Setup Guide →](?path=/docs/getting-started-setup--docs).

Clipboard writes through [`expo-clipboard`](https://docs.expo.dev/versions/latest/sdk/clipboard/), a peer dependency of the library. Install it in your app:

```sh
npx expo install expo-clipboard
```

### With a toast

Clipboard does not show a toast by itself. Use `onCopy` to trigger one:

```tsx
import { Clipboard, toast } from '@ledgerhq/lumen-ui-rnative';

<Clipboard
  value='0x71C7656EC7ab88b098defB751B7401B5f6d8976F'
  onCopy={() => toast.info({ title: 'Copied to clipboard' })}
/>;
```
