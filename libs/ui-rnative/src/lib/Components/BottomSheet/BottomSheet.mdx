## Introduction

BottomSheet provides a flexible and performant way to present content, forms, or actions in a mobile-friendly interface with support for scrollable content, dynamic sizing, and gesture controls.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=XXXXX&p=f&m=dev).

## Anatomy

<Canvas of={BottomSheetStories.Base} />

- **Handle**: Visual indicator for draggable area
- **Backdrop**: Semi-transparent overlay behind the sheet
- **Header**: Optional header with title, description, back button, and close button
- **Content**: Scrollable or static content
- **Footer**: Optional sticky area pinned to the bottom of the sheet

## Properties

### Overview

The base bottom sheet with standard configuration. This example uses `BottomSheetView` for static content, shows a compact header, and snaps to full height. Use this as your starting point for most implementations.

### Header Appearances

Bottom sheets support two header appearances:

- **compact**: Centered title with optional description (ideal for shorter titles)
- **expanded**: Left-aligned title with larger typography (ideal for longer titles and detailed descriptions)

The expanded appearance provides more breathing room for content-heavy headers and is recommended when your title exceeds 2-3 words or when you need to display substantial description text.

<Canvas of={BottomSheetStories.TitleExpanded} />

### Scrollable Content

#### ScrollView

Use `BottomSheetScrollView` when you have a moderate amount of scrollable content (typically under 20-30 items) that can safely fit in memory. Perfect for forms, article content, or settings menus. Note: Always use `BottomSheetScrollView`, not React Native's regular `ScrollView`.

<Canvas of={BottomSheetStories.ScrollView} />

#### FlatList (Virtual List)

Use `BottomSheetFlatList` for efficiently rendering large lists (100+ items) with simple data structures. It virtualizes items to improve performance by only rendering what's visible on screen. Ideal for contact lists, search results, or product catalogs. This example demonstrates a list with 100 items.

<Canvas of={BottomSheetStories.VirtualList} />

#### Sticky Header Content

You can set up a sticky header content in a `BottomSheetFlatList` or `BottomSheetScrollView` by using the `stickyHeaderIndices` prop.

<Canvas of={BottomSheetStories.StickyHeaderContent} />

#### VirtualizedList

Use `BottomSheetVirtualizedList` when you need more control over item access patterns or work with complex data structures. Requires explicit `getItem` and `getItemCount` implementations. This is the lower-level API that `FlatList` is built upon—use it for custom optimizations or non-array data sources.

<Canvas of={BottomSheetStories.VirtualizedList} />

> **Additional List Types:**
>
> - **SectionList**: Available via `BottomSheetSectionList` but **not compatible with react-native-web**. See [Gorhom documentation](https://gorhom.dev/react-native-bottom-sheet/components/bottomsheetsectionlist) for usage details.
> - **FlashList**: High-performance list from Shopify. Requires `@shopify/flash-list` package. See [Gorhom documentation](https://gorhom.dev/react-native-bottom-sheet/components/bottomsheetflashlist) for usage details.

### Dynamic Sizing

Bottom sheets can automatically adapt to content height instead of using fixed snap points. Enable this with `enableDynamicSizing` prop. The sheet will automatically resize as content changes—perfect for dynamic forms, expandable sections, or content that varies in length. This example shows a sheet that sizes itself to fit 5 items.

<Canvas of={BottomSheetStories.DynamicSizingWithoutSnapPoints} />

You can also combine snap points with dynamic sizing to control the height of the bottom sheet. This example shows a sheet that sizes itself to fit 3 items. Additionally, maxDynamicContentSize can be used to control the max height of the bottom sheet (not working on web preview).

<Canvas of={BottomSheetStories.DynamicSizingWithSnapPoints} />

- `enablePanDownToClose={false}`
- `backdropPressBehavior='none'`

### Footer

`BottomSheetFooter` renders a sticky area pinned below the scrollable region.

`BottomSheetContent` is a non-scrollable content block that applies standard paddings.

#### BottomSheetContent

Gorhom's `BottomSheetView` is `position: absolute; top: 0`, so it always overlaps content above it-including the header. For this reason you cannot nest a second `BottomSheetView` inside another one to wrap your body content.

When using dynamic sizing (`enableDynamicSizing`), everything must live inside a single Gorhom-aware wrapper (`BottomSheetView`) so the library can measure the total height correctly. That rules out an extra `BottomSheetView` as a content wrapper.

`BottomSheetContent` solves this: it is a plain `Box`-based container (not a Gorhom component) with the standard horizontal and vertical paddings already built in, so you get consistent spacing without fighting the absolute-positioning constraint.

#### Automatic padding stripping

To avoid double-padding, `BottomSheetContent` and `BottomSheetFooter` communicate with their parent via React context:

- If `BottomSheetContent` is a child of `BottomSheetView`, its `paddingHorizontal` is dropped (the view already provides it).
- If a `BottomSheetFooter` is present inside the bottom sheet, `BottomSheetContent` drops its `paddingBottom` (the footer already handles the bottom spacing).

This means all combinations—with/without dynamic sizing, with/without a footer—produce consistent spacing automatically.

## Setup

Install and set up the library with our [Setup Guide →](?path=/docs/getting-started-setup--docs).
BottomSheet is built on top of [@gorhom/bottom-sheet v5](https://gorhom.dev/react-native-bottom-sheet/).

### Required Provider

`BottomSheetModalProvider` must be placed **inside** `GestureHandlerRootView` in your app:

```tsx
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import { BottomSheetModalProvider } from '@ledgerhq/lumen-ui-rnative';

// Inside your app, after GestureHandlerRootView
<GestureHandlerRootView style={{ flex: 1 }}>
  <BottomSheetModalProvider>
    {/* Your app content and BottomSheet components */}
  </BottomSheetModalProvider>
</GestureHandlerRootView>
```

> **Note:** The provider must be inside `GestureHandlerRootView` because BottomSheet uses gestures for drag and swipe interactions.  

### Basic Usage

```tsx
import { BottomSheet, BottomSheetView, BottomSheetHeader, useBottomSheetRef, Box, Text } from '@ledgerhq/lumen-ui-rnative';
import { Button } from '@ledgerhq/lumen-ui-rnative';

function MyComponent() {
  const bottomSheetRef = useBottomSheetRef();

  return (
    <>
      <Button onPress={() => bottomSheetRef.current?.present()}>
        Open Bottom Sheet
      </Button>

      <BottomSheet ref={bottomSheetRef} snapPoints="full">
        <BottomSheetView>
          <BottomSheetHeader
            title="Welcome"
            density="compact"
            description="Get started with our platform"
          />
          <Text typography='body2' lx={{ color: 'base' }}>Your content here</Text>
        </BottomSheetView>
      </BottomSheet>
    </>
  );
}
```

### BottomSheet hooks API

The `useBottomSheetRef` hook provides a typed ref for programmatic control outside of the BottomSheet component:

```tsx
import { useBottomSheetRef } from '@ledgerhq/lumen-ui-rnative';

const MyComponent = () => {
  const bottomSheetRef = useBottomSheetRef();

  return (
    <BottomSheet ref={bottomSheetRef} snapPoints={['25%', '50%', '90%']}>
      {/* Content */}
    </BottomSheet>
  );
}
```

The `useBottomSheet` hook provides a typed ref for programmatic control inside of the BottomSheet component:

```tsx
import { useBottomSheet } from '@ledgerhq/lumen-ui-rnative';

const Content = () => {
  const { snapToIndex } = useBottomSheet();
  return (
    <Pressable onPress={() => snapToIndex(1)}>Expand to next snap point</Pressable>
  );
};

const MyComponent = () => {
  return (
    <BottomSheet>
      <BottomSheetView>
        <Content />
      </BottomSheetView>
    </BottomSheet>
  );
}
```

### Snap Points

```tsx
// Preset snap points
<BottomSheet snapPoints="full">    {/* 95% of screen */}
<BottomSheet snapPoints="medium">    {/* 50% of screen */}
<BottomSheet snapPoints="small"> {/* 25% of screen */}

// Custom snap points (pixels, percentages, or mixed)
<BottomSheet snapPoints={[200, 400, 600]}>
<BottomSheet snapPoints={['30%', '60%', '90%']}>
<BottomSheet snapPoints={[150, '50%', '90%']}>
```

### Scrollable Components

Always use specialized scrollable components, never regular React Native components:

```tsx
import { 
  BottomSheetView,           // Static content
  BottomSheetScrollView,      // Scrollable content
  BottomSheetFlatList,        // Large lists (100+ items)
  BottomSheetVirtualizedList, // Custom data access patterns
} from '@ledgerhq/lumen-ui-rnative';

// Use spacing prop on header when using list components
<BottomSheet ref={ref} snapPoints="full">
  <BottomSheetHeader spacing title="List" density="compact" />
  <BottomSheetFlatList data={data} renderItem={renderItem} />
</BottomSheet>
```

### Footer and Content

#### BottomSheetFooter

`BottomSheetFooter` renders a sticky area at the bottom of the sheet. It must be placed inside a `BottomSheet` (context is required).

#### BottomSheetContent

`BottomSheetContent` is a non-scrollable `Box`-based container with `lx` support. By default it applies horizontal and vertical paddings.

Use it as the body wrapper whenever you need a static (non-scrollable) content area inside a `BottomSheetView`. Do **not** use a second `BottomSheetView` for this purpose. Gorhom's `BottomSheetView` is `position: absolute; top: 0`, so nesting one inside another causes it to overlap the header rather than flow below it. `BottomSheetContent` is a plain `Box` that avoids this constraint entirely.

When using dynamic sizing, all content must live inside a single `BottomSheetView` so the library can measure the sheet height. `BottomSheetContent` works correctly in this setup; a nested `BottomSheetView` does not.

Padding is handled automatically via context:
- `paddingHorizontal` is stripped when `BottomSheetContent` is a child of `BottomSheetView` (the view already provides it).
- `paddingBottom` is stripped when a `BottomSheetFooter` is present (the footer owns the bottom spacing).

#### Pattern A: scrollable content with a footer as siblings

Footer and scrollable are direct children of `BottomSheet`.

```tsx
import {
  BottomSheet,
  BottomSheetHeader,
  BottomSheetScrollView,
  BottomSheetFooter,
  useBottomSheetRef,
} from '@ledgerhq/lumen-ui-rnative';

function MyComponent() {
  const ref = useBottomSheetRef();

  return (
    <BottomSheet ref={ref} snapPoints={['50%']}>
      <BottomSheetHeader spacing title="Title" density="compact" />
      <BottomSheetScrollView>
        {/* scrollable content */}
      </BottomSheetScrollView>
      <BottomSheetFooter>
        <Button size="lg" isFull>Confirm</Button>
        <Button size="lg" isFull appearance="ghost">Cancel</Button>
      </BottomSheetFooter>
    </BottomSheet>
  );
}
```

#### Pattern B: static content with a footer inside BottomSheetView

Both `BottomSheetContent` and `BottomSheetFooter` are children of `BottomSheetView`.

```tsx
import {
  BottomSheet,
  BottomSheetView,
  BottomSheetHeader,
  BottomSheetContent,
  BottomSheetFooter,
  useBottomSheetRef,
} from '@ledgerhq/lumen-ui-rnative';

function MyComponent() {
  const ref = useBottomSheetRef();

  return (
    <BottomSheet ref={ref} snapPoints={null} enableDynamicSizing>
      <BottomSheetView>
        <BottomSheetHeader title="Title" density="compact" />
        <BottomSheetContent lx={{ gap: 's12' }}>
          {/* static content */}
        </BottomSheetContent>
        <BottomSheetFooter>
          <Button size="lg" isFull>Confirm</Button>
          <Button size="lg" isFull appearance="ghost">Cancel</Button>
        </BottomSheetFooter>
      </BottomSheetView>
    </BottomSheet>
  );
}
```

#### Pattern C: standalone BottomSheetContent without a scrollable parent

`BottomSheetContent` is a direct child of `BottomSheet`, not wrapped in any scrollable.

```tsx
<BottomSheet ref={ref} snapPoints={['50%']}>
  <BottomSheetHeader spacing title="Title" density="compact" />
  <BottomSheetContent>
    {/* content */}
  </BottomSheetContent>
  <BottomSheetFooter>
    <Button size="lg" isFull>Confirm</Button>
  </BottomSheetFooter>
</BottomSheet>
```

### Important Notes

- **Dynamic Sizing**: When using `enableDynamicSizing`, do not define `snapPoints`
- **Header Spacing**: Use `spacing` prop on `BottomSheetHeader` when using FlatList/VirtualizedList or when the footer is a sibling of a list-based scrollable
- **SectionList**: Not compatible with react-native-web. See [Gorhom documentation](https://gorhom.dev/react-native-bottom-sheet/components/bottomsheetsectionlist).
- **FlashList**: Requires `@shopify/flash-list` package. See [Gorhom docs](https://gorhom.dev/react-native-bottom-sheet/components/bottomsheetflashlist)
