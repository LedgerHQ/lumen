# MenuList

## Introduction

`MenuList` is a container for a set of tappable actions. Each `MenuListItem` displays a label, an optional leading icon, and supports `base` and `red` appearances.

## Properties

### Appearance

`MenuListItem` supports two appearances: `base` (default) for standard actions and `red` for irreversible or dangerous operations such as deleting or unlinking. The red appearance renders the label and icon in the error colour.

Place `red` items **last** in the list. Both the Apple HIG and Material guidelines put destructive actions at the bottom, away from the items a user reaches for by habit. `MenuList` does not enforce the order.

<Canvas of={MenuListStories.AppearanceShowcase} />

### Disabled

Set `disabled` on individual `MenuListItem`s to prevent interaction. The label and icon are rendered in the disabled colour and the press handler is suppressed.

<Canvas of={MenuListStories.DisabledShowcase} />

## Accessibility

Each `MenuListItem` has `accessibilityRole='button'` and sets `accessibilityState={{ disabled }}` to reflect its interaction state to assistive technologies.
