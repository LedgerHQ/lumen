# Security Policy

## Supported Versions

Lumen is pre-1.0. Security fixes ship in the latest published version of each
`@ledgerhq/lumen-*` package only; upgrade to receive them.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest `0.x`   | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions or pull requests.

Report them to the Ledger Donjon security team through the bug bounty program:
https://donjon.ledger.com/bounty/
