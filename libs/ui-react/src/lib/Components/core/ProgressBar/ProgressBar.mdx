# ProgressBar

<CustomTabs>
  <Tab label="Overview">

The ProgressBar shows how far along a task is, such as an upload, a sync or an onboarding checklist. It fills a track from 0 to 100 and can show an optional label above or below the bar.

## Properties

<Controls of={ProgressBarStories.Base} />

### Value

`value` is a number from 0 to 100. Values outside the range are clamped.

The fill animates to its new width in 200ms with an ease-out curve.

<Canvas of={ProgressBarStories.ValueShowcase} />

### Appearance

Five appearances carry meaning and are driven by the state of the task: `base` (default), `accent`, `success`, `error` and `warning`.

Eight `decorative-*` appearances (`blue`, `pink`, `purple`, `green`, `turquoise`, `yellow`, `orange`, `red`) are available for identity or categorization.

> ⚠️ Decorative appearances are not for status. Use `success`, `error` or `warning` to communicate the state of a task.
  
<Canvas of={ProgressBarStories.AppearanceShowcase} />

### Label

Pass `label` to show a label. It also names the bar for assistive technology.

<Canvas of={ProgressBarStories.WithLabel} />

`labelPosition` places the label above or below the bar, aligned to the start or end edge. The default is `start-bottom`. `start` and `end` follow the text direction.

<Canvas of={ProgressBarStories.LabelPositionShowcase} />

The label can contain more than text:

## Responsive behavior

The track spans the full width of its container, so size the bar by sizing its container. Its height is fixed at 6px.

## Accessibility

- The bar has `role="progressbar"` with `aria-valuemin` 0, `aria-valuemax` 100 and `aria-valuenow` set to the clamped value.
- Every bar needs an accessible name, and TypeScript requires either `label` or `aria-label`.
- Pair the bar with visible text so color is never the only signal.

### Accessible name

- **With a `label`**: the label names the bar, and you don't need `aria-label`.
- **Without a visible label**: pass `aria-label`, for example `aria-label='Upload progress'`.
- **When the spoken name should differ from the visible text**: pass both. `aria-label` takes precedence over `label` for assistive technology, while the label stays visible.
