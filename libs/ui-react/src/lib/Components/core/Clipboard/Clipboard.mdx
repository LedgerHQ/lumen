# Clipboard

<CustomTabs>

## Introduction

**Clipboard** copies a value the user needs, such as an address, an ID or a code. It owns the copy behavior and the copied state; the element it renders only triggers it. Clicking copies the value and switches the copy icon to a check icon for 3 seconds by default.

Clipboard renders nothing by itself: its `render` prop returns the element that triggers the copy. Render a **ClipboardInput**, a full-width surface displaying the value, or any other component, such as a `Button` or an `IconButton`.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=23359-110294).

## Anatomy

- **Clipboard**: the behavior. It copies `value`, tracks the copied state and passes it to `render`.
- **ClipboardInput**: the input-style visual. It displays a `label` (long values wrap onto multiple lines) and an `icon`; hovering anywhere on it highlights the icon.

### Custom render

`render` receives the copy state and returns the element that triggers the copy:

- `handleCopy`: copies the value. Resolves `false` when the copy fails or Clipboard is disabled, e.g. to show an error.
- `Icon`: the copy icon, or the check icon while the copied state lasts.
- `statusLabel`: the translated "Copy" label, or "Copied" while the copied state lasts.
- `isCopied` and `value`, for anything else.

<Canvas of={ClipboardStories.WithCustomRender} />

## Accessibility

- ClipboardInput renders a native `button`, reachable with the keyboard and activated with `Enter` or `Space`.
- Use `statusLabel` in the trigger's accessible name: the value followed by "Copy" for a ClipboardInput, or "Copy" alone for an `IconButton`'s `aria-label`. It switches to "Copied" once the value is copied (translated with the library locale).
- Clipboard also announces "Copied" through a visually hidden polite live region, since screen readers don't re-read the name of the focused trigger when it changes.
- The copied state only shows when the clipboard write succeeds; it is skipped when the browser denies clipboard access (insecure context or missing permission).
