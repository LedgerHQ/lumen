# Legend

A display-only key for chart series or segments. Each item shows a color swatch
and a label. The legend is composable next to `DonutChart` and `LineChart` and
does not drive or react to chart interaction state.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=16550-7583).

## Usage

Pass an array of `LegendItem`s. `DonutSegment[]` is assignable as-is; for
`LineChart`, map each `Series` to `{ id, label, color: stroke }`.

<Canvas of={LegendStories.Base} />
