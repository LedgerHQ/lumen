# Spot

## Introduction

Spots are circular icon containers. `appearance` selects a color palette. `fill` chooses whether that palette paints only the icon, or the circle as well.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=6786-4738).

## Anatomy

<Canvas of={SpotStories.Base} />

- **Circular container**: Transparent muted fill, or a solid fill from the palette
- **Icon**: Required. Status spots pass a filled symbol such as `CheckmarkCircleFill`

## Properties

<Canvas of={SpotStories.Base} />
<Controls of={SpotStories.Base} />

### Appearance

`appearance` is the color palette. On a transparent fill it colors the icon. On a plain fill it also paints the circle, using the palette's paired text color.

<Canvas of={SpotStories.AppearanceShowcase} />

### Fill

`transparent` keeps the muted transparent circle. `plain` uses the palette's solid background.

<Canvas of={SpotStories.FillShowcase} />

### Size

<Canvas of={SpotStories.SizeShowcase} />

### With DotSymbol

A coin badge stays a `DotSymbol` wrapped around the spot.

<Canvas of={SpotStories.WithDotSymbol} />

### Loading

Pass `Spinner` as the icon to keep the circle around a loading indicator. Spot sizes the spinner from its own size.

<Canvas of={SpotStories.WithSpinner} />

## Accessibility

The icon should have an accessible name when the spot conveys status. Color alone does not communicate the state.
