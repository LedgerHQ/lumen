# DonutChart

An allocation / part-to-whole chart. It renders a ring of segments sized by
their share of the total, drawn as an SVG.

> View in [Figma](https://www.figma.com/design/JxaLVMTWirCpU0rsbZ30k7/2.-Components-Library?node-id=17763-34880).

## Usage

`DonutChart` owns its `series` data and renders exactly the segments it
receives — grouping ("top N + other") is handled outside the component. Each
segment's angle is its `value` as a fraction of the summed total; segments are
laid out in series order, clockwise from 12 o'clock, with rounded caps and gaps.

## Basics

Define your data as an array of `DonutSegment`s. Each segment needs a stable
`id`, a `label`, and a raw `value`; `color` is optional.

## Interactivity

Segments are hoverable by default. Hovering a segment sets `activeId`, dims
non-active segments to 30% opacity, and pops the active slice out radially.
Leaving the chart container resets `activeId` to `null`.

Use `activeId` / `onActiveIdChange` for controlled mode so a legend or center
slot can react to the same active segment.

<Canvas of={DonutChartStories.Interactive} />


## Center content

`renderCenter` renders content in the middle of the ring from `DonutChartTitle`
and `DonutChartDescription`. Layout and pointer events are handled internally.
Used alone, its `activeSegment` param (enriched with `percent`, `null` when
nothing is active) lets you switch content in one callback, e.g. a ternary.

Pass `renderCenterActive` alongside it to crossfade between resting and active
layouts on hover instead: `renderCenter` then always gets `activeSegment: null`
(resting only), while `renderCenterActive` handles the active layout.

Both `DonutChartTitle` and `DonutChartDescription` cap their width to the
ring's inner diameter, so long content truncates instead of overlapping the
ring. In `DonutChartDescription`, mark the truncatable part of `children`
(e.g. the label, not a trailing icon) with a `truncate` class so it shrinks
while the icon stays fixed-size.
